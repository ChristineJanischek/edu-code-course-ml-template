# Schnellstart für Grundlagen und Vertiefung

1. Auf der Vorlagenseite **Use this template → Create a new repository** wählen. Das eigene Repository öffnen und **Code → Codespaces → Create codespace on main** wählen. Alternativ die ZIP laden und lokal entpacken.
2. `lernskripte/ML_R8_Grundlagen_BKWI1_A4_Desktop_Prueffassung.pdf` öffnen. Für die BKWI2-Wiederholung anschließend `lernskripte/ML_R8_Vertiefung_BKWI2_A4_Desktop_Prueffassung.pdf` öffnen. Die A5-Dateien sind für kleine Bildschirme gedacht.
3. Im Kapitel das Aufgabenblatt `.1`, Informationsblatt `.2` und bei Bedarf Vertiefungsblatt `.3` verwenden. Unter `aufgaben/ML-Kxx-A01.md` steht eine offline lesbare Textkopie.
4. Vor einem Notebook-Start zuerst die CSV-Kopfzeile ansehen. Öffne eine passende `.ipynb`-Datei aus `notebooks/` oder die gleichnamige `.py`-Datei aus `programme/`. Die Starter enthalten keine fertige Aufgabenlösung.
5. Eigene Ergebnisse in `abgaben/ML-Kxx-A01/` speichern. Für `git clone`, `git add`, `git commit` und `git push` erklärt [Konsole und Git](02_KONSOLE_UND_GITHUB.md) Zweck und Eingabe.

Im Codespace `python tests/vorabcheck.py` ausführen. Lokal ohne Jupyter genügt `python tests/offline_python_check.py`. Fehlt ein Paket, die Lehrkraft nach der Schulinstallation fragen; nicht ungeprüft auf dem Schulgerät installieren. Die fachlichen Aufgaben können zunächst auf Papier oder in Word bearbeitet werden.
